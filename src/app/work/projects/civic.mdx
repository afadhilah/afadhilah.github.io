## Project Summary

Civic Spotlight is an interactive web platform that enables Indonesian citizens to report public infrastructure issues in real-time with spatial visualization based on maps. The platform is designed to increase transparency and community participation in public infrastructure improvements with community collaboration features.

### Purpose of Creation

This project was built to achieve several strategic objectives:

1. **Transparency** - Provide an open platform for reporting infrastructure issues
2. **Community Participation** - Enable community collaboration through upvotes and comments
3. **Real-time Tracking** - Provide project progress status updates in real-time
4. **Spatial Data** - Visualize reports in map format for geographic analysis
5. **Accountability** - Document and track each report from start to finish

## Database Schema

### Users Table

Stores user information and authentication credentials.

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(255) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  password VARCHAR(255) NOT NULL,
  phone VARCHAR(20),
  address TEXT,
  avatar_url VARCHAR(255),
  role VARCHAR(50) DEFAULT 'user',
  status VARCHAR(50) DEFAULT 'active',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

### Reports Table

Main infrastructure report data with location and status information.

```sql
CREATE TABLE reports (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  title VARCHAR(255) NOT NULL,
  description TEXT NOT NULL,
  category VARCHAR(50) NOT NULL,
  status VARCHAR(50) DEFAULT 'pending',
  location VARCHAR(255) NOT NULL,
  latitude DECIMAL(10, 8) NOT NULL,
  longitude DECIMAL(11, 8) NOT NULL,
  photo_url VARCHAR(255),
  upvotes INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

### Comments Table

Community collaboration through discussions on each report.

```sql
CREATE TABLE comments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  report_id UUID NOT NULL REFERENCES reports(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

### Upvotes Table

Tracking upvotes per user to prevent duplication and calculate priority.

```sql
CREATE TABLE upvotes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  report_id UUID NOT NULL REFERENCES reports(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(report_id, user_id)
)
```

### Report Timeline Table

Progress tracking for reports from pending to completed.

```sql
CREATE TABLE report_timeline (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  report_id UUID NOT NULL REFERENCES reports(id) ON DELETE CASCADE,
  step VARCHAR(255) NOT NULL,
  done BOOLEAN DEFAULT FALSE,
  date TIMESTAMP,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

Reporting features include:

- **GPS Location** - Latitude/longitude coordinates from map picker or GPS device
- **Detailed Description** - Title and description for context
- **Status Progress** - Pending, In Progress, Resolved tracking
- **Timestamps** - Created_at and updated_at for audit trail

Leaflet integration for real-time spatial report visualization.

### 4. Priority System (Upvotes)

Community voting mechanism to determine repair priority.

- Users can upvote reports to show support
- Each user can only upvote once per report (UNIQUE constraint)
- Upvote counter auto-updates

### 6. Search & Filter

Search and filter reports based on various criteria.

- Filter by category
- Filter by status (pending, in progress, resolved)
- Search text on title, description, and location
- Pagination support for optimal performance

### 7. Responsive Design

Fully responsive application for desktop, tablet, and mobile.

- Mobile-first approach with Tailwind CSS
- Adaptive layouts for various screen sizes
- Touch-friendly interface for mobile devices
