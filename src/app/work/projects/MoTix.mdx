## 🛠 Tech Stack & Programming Language

This project uses **Dart** as the primary programming language which renders UI/UX through **Flutter** framework. On the backend side, the project relies entirely on **Firebase** as a Backend-as-a-Service (BaaS) solution, thus not requiring a separate independent server.

## 📐 Architecture & Design

<AccordionGroup>
  <Accordion title="System Architecture (Serverless BaaS)">
    <Text variant="body-default-m" onBackground="neutral-medium" marginBottom="16">
      This application adopts a **Serverless** architecture pattern via *Backend-as-a-Service* (BaaS). On the client side (Client-Side), the *app mobile* is developed using **Dart/Flutter**. The client interacts using <i>native SDK</i> directly to Cloud Firestore & Firebase Auth without any custom backend intermediary. Additionally, on the client side there is external HTTP Request instruction processing via REST API in asynchronous data form (JSON communication) to TMDB API. All real-time data processing is facilitated by Firebase's *event-driven* architecture.
    </Text>
