## Tentang Artharum

**Artharum** adalah aplikasi Android native yang dirancang untuk membantu Anda mencatat dan mengelola keuangan pribadi dengan mudah. Aplikasi ini menyediakan tools lengkap untuk tracking transaksi, mengelola multiple accounts, menetapkan budget, dan menganalisis pengeluaran dengan visualisasi data yang intuitif.

### Tujuan Aplikasi

Artharum dibuat untuk memenuhi kebutuhan:
- **Mencatat transaksi** - Income, expense, dan transfer antar akun
- **Mengelola multiple accounts** - Cash, bank, e-wallet, kartu kredit
- **Monitoring budget** - Set limit per kategori dan track progress
- **Analisis pengeluaran** - Visualisasi distribusi dan tren keuangan
- **Membuat keputusan finansial** - Data-driven insights untuk perencanaan keuangan

## Arsitektur

Artharum dibangun menggunakan **Clean Architecture** yang dikombinasikan dengan **MVVM (Model-View-ViewModel)** pattern.

### Layer Architecture

```
┌──────────────────────────────────────────────┐
│         Presentation Layer (UI)              │
│    (Composable, ViewModel, Screen)           │
└──────────────────────────────────────────────┘
                    ↓ ↑
┌──────────────────────────────────────────────┐
│     Domain Layer (Business Logic)            │
│  (UseCase, Repository Interface, Entity)    │
└──────────────────────────────────────────────┘
                    ↓ ↑
┌──────────────────────────────────────────────┐
│     Data Layer (Database & Repository)      │
│  (Room DAO, Entity DB, Repository Impl)     │
└──────────────────────────────────────────────┘
```

### 1. Presentation Layer

Bertanggung jawab untuk menampilkan UI dan menangani user interaction.

**Komponen:**
- **Composable** - UI components menggunakan Jetpack Compose
- **ViewModel** - Mengelola state dan business logic untuk UI
- **Screen/Page** - Container untuk navigasi
- **Event** - User interaction event

**Technology:**
- Jetpack Compose
- StateFlow untuk state management
- Navigation Component

**Struktur:**
```
ui/
├── screen/
│   ├── dashboard/
│   ├── transaction/
│   ├── account/
│   └── budget/
├── component/
│   ├── Card components
│   ├── Charts
│   └── Custom UI elements
├── viewmodel/
│   └── ViewModel untuk setiap screen
└── navigation/
    └── Navigation graph
```

### 2. Domain Layer

Layer yang berisi business logic dan tidak tergantung pada framework.

**Komponen:**
- **UseCase** - Encapsulate business logic, satu use case = satu fungsi bisnis
- **Entity** - Model domain (representasi data bisnis)
- **Repository Interface** - Contract untuk data access

**Contoh UseCase:**
- `GetAllTransactionsUseCase` - Retrieve semua transaksi
- `CreateTransactionUseCase` - Buat transaksi baru
- `GetBudgetUseCase` - Ambil budget setting
- `CalculateNetBalanceUseCase` - Hitung net balance

**Struktur:**
```
domain/
├── usecase/
│   ├── transaction/
│   ├── budget/
│   ├── account/
│   └── statistics/
├── entity/
│   ├── Transaction
│   ├── Account
│   ├── Budget
│   └── Category
└── repository/
    ├── TransactionRepository interface
    ├── AccountRepository interface
    └── BudgetRepository interface
```

### 3. Data Layer

Layer yang menangani penyimpanan dan pengambilan data.

**Komponen:**
- **Room Database** - Local database untuk offline storage
- **DAO (Data Access Object)** - Database queries
- **Entity (DB)** - Database models
- **Repository Implementation** - Implementasi interface dari domain layer
- **Mapper** - Convert antara DB entity dan domain entity

**Technology:**
- Room (SQLite)
- KSP (Kotlin Symbol Processing) untuk code generation

**Struktur:**
```
data/
├── local/
│   ├── dao/
│   │   ├── TransactionDao
│   │   ├── AccountDao
│   │   └── BudgetDao
│   ├── entity/
│   │   ├── TransactionEntity (DB)
│   │   ├── AccountEntity (DB)
│   │   └── BudgetEntity (DB)
│   └── AppDatabase.kt
├── repository/
│   ├── TransactionRepositoryImpl
│   ├── AccountRepositoryImpl
│   └── BudgetRepositoryImpl
└── mapper/
    ├── TransactionMapper
    ├── AccountMapper
    └── BudgetMapper
```

- **Android SDK 36.0.0** atau lebih tinggi
- **Android Emulator** atau **Physical Device** dengan Android 12+ (API 31+)

### Quick Start

#### Run di Physical Device

```powershell
.\run-device.ps1
```

Script ini akan:
1. Build debug APK
2. Install ke physical device
3. Launch aplikasi secara otomatis

#### Run di Emulator

```powershell
.\run-android.ps1
```

Script ini akan:
1. Build debug APK
2. Install ke emulator yang sedang running
3. Launch aplikasi secara otomatis

#### Build Only

```powershell
.\gradlew.bat :app:assembleDebug
```

Hanya build APK tanpa install dan launch.

### Compile Check

Untuk cek apakah code compile tanpa error:

```powershell
.\gradlew.bat :app:compileDebugKotlin
```

## Data Flow

Berikut adalah flow data dari User Input hingga Display:

```
User Action (Click, Input)
           ↓
   ViewModel (Handle Event)
           ↓
   UseCase (Execute Business Logic)
           ↓
   Repository Interface
           ↓
   Repository Implementation
           ↓
   Room DAO (Database Query)
           ↓
   Database (SQLite via Room)
           ↓
   Response (Data back up through layers)
           ↓
   ViewModel (Update State)
           ↓
   Composable (Recompose & Display)
           ↓
   User Sees Updated UI
```
