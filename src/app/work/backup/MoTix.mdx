<Text variant="body-default-l" marginBottom="16" onBackground="neutral-medium">
  MoTix adalah aplikasi *mobile* terintegrasi yang dirancang untuk memberikan pengalaman komprehensif dalam menjelajahi dan memesan tiket film bioskop. Aplikasi ini menjadi solusi *all-in-one* bagi penikmat film, menyediakan akses ke data film secara *real-time* yang ditarik menggunakan The Movie Database (TMDB) API (RESTful), mulai dari sinopsis, poster, tanggal tayang, hingga rating. 
</Text>

<Text variant="body-default-l" marginBottom="24" onBackground="neutral-medium">
  Lebih dari sekadar direktori film, MoTix memiliki kapabilitas transaksi pengelolaan tiket bioskop yang interaktif (termasuk pemilihan kursi dan generasi QR Code), manajemen daftar tontonan (Watchlist) yang tersinkronisasi ke cloud, dan ekosistem komunitas melalui fitur Ulasan (Review) pengguna.
</Text>

## 🛠 Tech Stack & Bahasa Pemrograman

Proyek ini menggunakan **Dart** sebagai bahasa pemrograman utama yang merender UI/UX lewat *framework* **Flutter**. Di sisi *backend*, proyek ini sepenuhnya bertumpu pada **Firebase** sebagai layanan *Backend-as-a-Service* (BaaS), sehingga tidak memerlukan server khusus independen.

## 📐 Arsitektur & Desain

<AccordionGroup>
  <Accordion title="Arsitektur Sistem (Serverless BaaS)">
    <Text variant="body-default-m" onBackground="neutral-medium" marginBottom="16">
      Aplikasi ini mengadopsi pola arsitektur **Serverless** via *Backend-as-a-Service* (BaaS). Di sisi klien (Client-Side), *app mobile* di-develop menggunakan **Dart/Flutter**. Klien berinteraksi menggunakan <i>SDK native</i> langsung ke Cloud Firestore & Firebase Auth tanpa adanya perantara *custom backend*. Selain itu, di sisi klien juga terdapat pemrosesan instruksi HTTP Request eksternal via REST API berbentuk data asinkron (komunikasi JSON) ke TMDB API. Semua pemrosesan data rill-time difasilitasi oleh arsitektur *event-driven* Firebase.
