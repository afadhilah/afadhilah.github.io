## 👋 Pengenalan Singkat

**BEM Insights Hub** adalah platform insights berbasis data yang dibangun khusus untuk **BEM ITS (Badan Eksekutif Mahasiswa - Institut Teknologi Sepuluh Nopember)**. Platform ini menggabungkan penelitian akademis, visualisasi data interaktif, analisis trend, dan dashboard admin dalam satu ekosistem yang modern dan user-friendly.

Platform ini dirancang dengan filosofi **brutalist design** yang memberikan kesan profesional, clean, dan fokus pada konten dengan animasi smooth dan efek glitch yang eye-catching.

---

## 🎯 Tujuan Project

BEM Insights Hub dibuat dengan tujuan utama:

1. **Sharing Research** - Menyediakan platform untuk mempublikasikan dan mengeksplorasi research findings yang evidence-based
2. **Data Visualization** - Menyajikan data kompleks dalam bentuk chart dan dashboard interaktif yang mudah dipahami
3. **Trend Analysis** - Melacak dan menganalisis trending topics dalam real-time
4. **Community Engagement** - Memberikan akses mudah kepada mahasiswa dan researcher untuk mengakses resources data
5. **Content Management** - Menyediakan admin dashboard untuk manajemen konten dan platform administration

## 🏗️ Arsitektur Project

### High-Level Architecture

```
BEM Insights Hub
│
├── Frontend (React 18 + TypeScript)
│   ├── Pages (Routing dengan React Router v6)
│   ├── Components (Reusable UI components)
│   ├── Hooks (Custom React hooks)
│   ├── State Management (React Query + Context)
│   └── Styling (Tailwind CSS + Framer Motion)
│
├── Build & Development
│   ├── Vite (Fast build tool)
│   ├── ESLint (Code quality)
│   ├── Vitest (Unit testing)
│   └── TypeScript (Type safety)
│
└── UI Library
    └── shadcn/ui (14+ reusable UI components)
```

- **Automatic Caching** - Data otomatis di-cache untuk performa optimal
