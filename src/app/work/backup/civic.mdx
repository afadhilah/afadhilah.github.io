## Ringkasan Proyek

Civic Spotlight adalah platform web interaktif yang memungkinkan masyarakat Indonesia untuk melaporkan masalah infrastruktur publik secara real-time dengan visualisasi spasial berbasis peta. Platform ini dirancang untuk meningkatkan transparansi dan partisipasi masyarakat dalam perbaikan infrastruktur publik dengan fitur kolaborasi komunitas.

### Tujuan Pembuatan

Proyek ini dibangun untuk mencapai beberapa tujuan strategis:

1. **Transparansi** - Menyediakan platform terbuka untuk melaporkan masalah infrastruktur
2. **Partisipasi Komunitas** - Memungkinkan masyarakat berkolaborasi melalui upvotes dan comments
3. **Real-time Tracking** - Memberikan status update progress perbaikan secara real-time
4. **Data Spasial** - Visualisasi laporan dalam format peta untuk analisis geografis
5. **Akuntabilitas** - Mendokumentasikan dan melacak setiap laporan dari awal hingga selesai

## Database Schema

### Users Table

Menyimpan informasi pengguna dan kredensial autentikasi.

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(255) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  password VARCHAR(255) NOT NULL,
  phone VARCHAR(20),
  address TEXT,
  avatar_url VARCHAR(255),
  role VARCHAR(50) DEFAULT 'user',
  status VARCHAR(50) DEFAULT 'active',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

### Reports Table

Data utama laporan infrastruktur dengan informasi lokasi dan status.

```sql
CREATE TABLE reports (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  title VARCHAR(255) NOT NULL,
  description TEXT NOT NULL,
  category VARCHAR(50) NOT NULL,
  status VARCHAR(50) DEFAULT 'pending',
  location VARCHAR(255) NOT NULL,
  latitude DECIMAL(10, 8) NOT NULL,
  longitude DECIMAL(11, 8) NOT NULL,
  photo_url VARCHAR(255),
  upvotes INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

### Comments Table

Kolaborasi komunitas melalui diskusi pada setiap laporan.

```sql
CREATE TABLE comments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  report_id UUID NOT NULL REFERENCES reports(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

### Upvotes Table

Tracking upvotes per user untuk mencegah duplikasi dan menghitung prioritas.

```sql
CREATE TABLE upvotes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  report_id UUID NOT NULL REFERENCES reports(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(report_id, user_id)
)
```

### Report Timeline Table

Progress tracking laporan dari pending hingga selesai.

```sql
CREATE TABLE report_timeline (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  report_id UUID NOT NULL REFERENCES reports(id) ON DELETE CASCADE,
  step VARCHAR(255) NOT NULL,
  done BOOLEAN DEFAULT FALSE,
  date TIMESTAMP,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

## Development Best Practices

### Code Organization

- **Components** - Reusable UI components di folder components/
- **Hooks** - Custom React hooks di folder hooks/ untuk logic reuse
- **Pages** - Full page components di folder pages/
- **Utils** - Helper functions di lib/utils.ts
- **Types** - TypeScript interfaces untuk type safety

### Frontend Development

- Gunakan TypeScript untuk type safety
- Components harus functional components dengan hooks
- Gunakan TanStack Query untuk server state management
- Styling dengan Tailwind CSS utility classes
- Icons dari Radix UI icon set
- Forms dengan React Hook Form + Zod validation

### Backend Development

- Controllers handle business logic
- Routes define API endpoints
- Middleware untuk cross-cutting concerns
- Database queries dengan parameterized statements
- Environment variables untuk sensitive data
- Error handling dengan try-catch dan middleware

### Security Considerations

- JWT tokens stored secara aman
- Passwords hashed dengan bcryptjs
- CORS configuration untuk origin control
- Request validation dengan express-validator
- File upload restricted ke specific types dan sizes
- SQL injection prevention dengan parameterized queries

## Troubleshooting

### Database Connection Issues

Jika mendapat error "connect ECONNREFUSED":

1. Verifikasi PostgreSQL running
2. Check .env credentials
3. Verifikasi host dan port
4. Gunakan Docker jika local PostgreSQL problematic

### CORS Issues

Jika frontend tidak bisa connect ke backend:

1. Check FRONTEND_URL di backend .env
2. Verifikasi VITE_API_URL di frontend .env.local
3. Pastikan backend running di port 5000
4. Clear browser cache

### File Upload Issues

Jika upload foto tidak bekerja:

1. Verifikasi Multer configuration di middleware/upload.js
2. Check backend/uploads/ folder permissions
3. Verifikasi file size (max 5MB)
4. Check MIME type whitelist

### Hot Reload Not Working

1. Restart Vite dev server
2. Restart Node.js backend
3. Clear node_modules dan reinstall
4. Verify vite.config.ts configuration
